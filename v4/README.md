# Lift Progression Tracker V4

V4 keeps the V3 dashboard/progression system and adds a faster workout workflow:
- Mobile-first workout logging
- Set-by-set reps and optional RIR
- Rest timer per exercise
- Workout notes
- Edit saved workouts
- Delete saved workouts
- Exercise progress and PR views
- JSON export/import backup
- Automatic migration from V2/V3 browser data when available
- Rear-delt fly remains removed
- Data remains local until a cloud database is connected
